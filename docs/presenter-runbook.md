# Presenter Runbook

1. Start the application.
2. Open `/demo/control`.
3. Enter the demo-control passcode.
4. Reset the current case if needed.
5. Select `ADDRESS_PEP_REVIEW`.
6. Open `/onboarding/start` in a second browser window.
7. Complete the customer journey through document upload and address confirmation.
8. Return to `/demo/control` and click `Clear review`.
9. Switch back to the customer window and show onboarding completion.
10. Copy the case ID and correlation ID for the audit reveal.
